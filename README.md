# ABYSS — Portfolio Website

A single-page portfolio website for Anirban Roy (aka Abyss), freelance video editor and CSE student.

## Publish using GitHub Pages (no terminal required)

1. Sign in to GitHub and open https://github.com/new
2. Repository name: `abyss-portfolio` (or any name you like).
3. Choose **Public**, then click **Create repository**.
4. On the new repository page, click **Add file → Upload files**.
5. Upload `index.html` from this folder. You may also upload this README.md.
6. Click **Commit changes**.
7. Open the repository's **Settings → Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**.
9. Set Branch to **main** and folder to **/(root)**, then click **Save**.
10. Wait a minute or two and refresh the Pages settings. GitHub will show the published website URL, usually `https://YOUR-USERNAME.github.io/abyss-portfolio/`.

## Updating the website

Edit `index.html` locally or in GitHub using the pencil **Edit** button, then commit the changes. GitHub Pages republishes automatically after a short delay.

## Notes

- The portrait is embedded inside `index.html`, so no separate image upload is required.
- The social links are included in the page. Check all links and replace any placeholder project details before sharing widely.
- The website is static HTML/CSS/JavaScript and does not need a build step.
